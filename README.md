# Alr Server
A custom [paper](https://github.com/PaperMC/Paper-archive) fork used by [AlrMc](https://mc.alr.re)

Aimed at fixing bugs, tweak details&improve the gaming experience, and enhanced stability

# Documentation

How To (Server Admins)
------
alr-paperclip is a jar file that you can download and run just like a normal jar file.

Download a copy of alr-paperclip.jar from [releases](http://github.com/Adallei/Alr/releases/).

Run the alr-paperclip jar directly from your server. Just like old times

Alr server requires [**Java 8**](http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html) or above.

How To (Compiling Jar From Source)

------tweak details to enhance the gaming experience

To compile Alr server, you need JDK 8, maven, and an internet connection.

Clone this repo, run `./alr jar` from *bash*, get files.
